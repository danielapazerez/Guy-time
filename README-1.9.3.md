# Guy Time PWA 1.9.3

## תיקוני התחברות באייפון

- נוספה התחברות עם אימייל וסיסמה, שנשמרת ישירות בתוך ה-PWA.
- נוספה אפשרות ליצירת חשבון חדש.
- כניסה באמצעות קישור/OTP נשארה כאפשרות משנית.
- כפתור שליחת המייל ננעל ל-60 שניות כדי למנוע חריגה ממגבלת השליחה.
- הודעות השגיאה של Supabase מוצגות בצורה ברורה יותר.
- Service Worker וה-cache עודכנו לגרסה 1.9.3.
- קריאת gen_random_bytes בקובצי SQL תוקנה ל-extensions.gen_random_bytes.

## הערה חשובה לאייפון

קישור Magic Link שנפתח מתוך המייל נפתח ב-Safari. ב-iOS, אחסון ההתחברות של Safari עשוי להיות נפרד מאחסון ה-PWA שהותקנה במסך הבית. לכן מומלץ להתחבר באפליקציה באמצעות אימייל וסיסמה.
