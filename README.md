# Guy Time 1.0

אפליקציית SwiftUI לניהול האכלות של גיא.

## Sprint 1
- טיימר מאז ההאכלה האחרונה
- טיימר הנקה ימין/שמאל בלחיצה להתחלה ובלחיצה נוספת לעצירה
- הדגשת צד ההנקה האחרון
- בקבוק: חלב אם שאוב או תמ״ל + מ״ל
- ויטמין D יומי
- היסטוריה, עריכה ומחיקה
- סטטיסטיקה
- שמירה מקומית במכשיר

## פתיחה והרצה
1. פתחו את `GuyTime.xcodeproj` ב-Xcode 16 ומעלה.
2. בחרו Team תחת Signing & Capabilities.
3. חברו iPhone או בחרו Simulator.
4. לחצו Run.

הפרויקט אינו כולל חתימה או פרופיל הפצה. התקנה על iPhone דורשת Mac עם Xcode ו-Apple ID; הפצה ב-TestFlight דורשת חשבון Apple Developer.
