# Guy Time — Sprint 1 v1.1

אפליקציית SwiftUI למעקב האכלה של גיא.

## כלול בגרסה
- טיימר מאז ההאכלה האחרונה
- טיימר הנקה לצד ימין ושמאל
- מעבר אוטומטי בין צדדים ושמירת הצד הקודם
- הדגשת צד ההנקה האחרון
- בקבוק: חלב אם שאוב / תמ״ל, שדה מ״ל וכפתורי כמות מהירים
- ויטמין D יומי
- היסטוריה עם עריכה ומחיקה
- סטטיסטיקה להיום, 7 ימים וכל התקופה
- שמירה מקומית, כולל טיימר הנקה פעיל
- ממשק RTL ומשוב רטט לפעולות מרכזיות

## פתיחה
יש לפתוח את `GuyTime.xcodeproj` ב-Xcode על Mac ולהריץ על iPhone או Simulator.
