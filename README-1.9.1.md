# Guy Time 1.9.1

תיקון מלא להתחברות ולסנכרון משפחתי.

## לפני העלאה ל-GitHub
1. ב-Supabase פתחי SQL Editor.
2. הדביקי והריצי את `GUYTIME-SUPABASE-MIGRATION-1.9.1.sql` פעם אחת.
3. העלי את כל קובצי התיקייה ל-GitHub והחליפי את הקבצים הקיימים.
4. באייפון פתחי את האתר ורענני פעם אחת. אם מותקנת אפליקציה במסך הבית, סגרי ופתחי מחדש.

## כניסה
האפליקציה מאפשרת הזנת קוד OTP בתוך Guy Time, וכן ממשיכה לתמוך בקישור הכניסה. כדי שהקוד יופיע במייל, בתבנית Magic Link של Supabase יש לכלול את המשתנה `{{ .Token }}`.

## סנכרון
- כל שינוי נשמר מקומית מיד.
- חזרה לאינטרנט מפעילה סנכרון אוטומטי.
- עריכות ומחיקות מסונכרנות באמצעות `updated_at` ו-`deleted_at`.
- אירועים נשלחים בנפרד ולא כל ההיסטוריה בכל פעולה.
