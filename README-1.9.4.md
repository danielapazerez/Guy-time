# Guy Time PWA 1.9.4

## תיקון חיבור שני הורים לאותה משפחה

- **חדש: כפתור "עזיבת המשפחה"** במסך המשפחה — מי שנתקע במשפחה לבד יכול לעזוב ולהצטרף עם קוד.
- **join_family חכם**: מי שיצר בטעות משפחה משלו (והוא היחיד בה) — ההצטרפות עם קוד תעביר אותו אוטומטית למשפחה הנכונה. השגיאה "already in family" תופיע רק אם יש בני משפחה נוספים.
- **תיקון תקיעה אחרי התחברות**: העבודה מול Supabase לא רצה יותר בתוך onAuthStateChange (דפוס שגרם למסך לא להתעדכן אחרי התחברות בסיסמה).
- **סנכרון מלא אחרי מעבר משפחה**: כשעוברים למשפחה אחרת, כל ההיסטוריה המקומית מסומנת להעלאה מחדש כדי שתגיע למשפחה החדשה.
- **קוד הזמנה בלי pgcrypto**: יצירת קוד לא תלויה יותר ב-extensions.gen_random_bytes.

## חובה: להריץ את קובץ ה-SQL החדש

יש להריץ ב-Supabase (SQL Editor) את הקובץ `GUYTIME-SUPABASE-MIGRATION-1.9.4.sql` פעם אחת.
בלי זה, כפתור העזיבה וההצטרפות האוטומטית לא יעבדו (תופיע הודעה "הגדרת הסנכרון ב-Supabase עדיין לא הושלמה").

## איך מחברים את שני ההורים

1. כל הורה מתחבר עם אימייל וסיסמה משלו (במכשיר שלו).
2. הורה אחד לוחץ "יצירת משפחה" ומעתיק את הקוד.
3. ההורה השני מזין את הקוד ולוחץ "הצטרפות". אם הוא יצר משפחה בטעות קודם — זה יסתדר אוטומטית.
